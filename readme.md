# Домашнее задание к работе 4

## Условие задачи
3. Дележка пиццы
Друзья заказали пиццу. Они решат, резать ее на 4 или 6 кусков, по простому правилу: если ровно один из них (Ваня A или Петя B) проголодался (его "уровень голода" - четное число), то резать на 4 части. Запишите условие для нарезки на 4 части.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Подключить заголовочные файлы <stdio.h>, <stdlib.h>, <locale.h>; определить макрос _CRT_SECURE_NO_DEPRECATE для отключения предупреждений о небезопасных функциях.
3. Объявить прототип функции int task(int A, int B).
4. В main() объявить целочисленные переменные A, B, pieces.
5. Установить русскую локаль через setlocale(LC_ALL, "RUS").
6. Вывести заголовок «Дз: Деление пиццы» и запросы на ввод значений A (голод Вани) и B (голод Пети).
7. Считать значения A и B с помощью scanf.
8. Вызвать функцию task(A, B) и сохранить результат в переменную pieces.
9. В функции task: проверить условие (A % 2) != (B % 2) — если остатки от деления A и B на 2 различаются, вернуть 4, иначе вернуть 6.
10. Вывести результат: «Резать пиццу на X», где X — значение pieces. Завершить программу, вернув 0.
11. **Конец**

## 2. Реализация программы

#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <stdlib.h>
#include <locale.h>


int task( int A, int B);

int main()
{
    int A,B,pieces;

    setlocale(LC_ALL, "RUS");

    printf("Дз: Деление пиццы\n");
    printf("Насколько голоден Ваня (A): ");
    scanf("%d", &A);
    printf("Насколько голоден Петя (B): ");
    scanf("%d", &B);

    pieces = task(A, B);
    printf("Резать пиццу на %d\n", pieces);

    return 0;
}

int task(int A, int B)
{
    return ((A % 2) != (B % 2) ? 4:6);
}
